# Аудит ліцензій — 2026-09-15

## Висновок

Основна ліцензія сервісу — EUPL-1.2, відповідно до наявного LICENSE.
На рівні задекларованих ліцензій Python-пакетів конфліктів із поточним
використанням як окремих бібліотек не виявлено. **Повне виконання умов
розповсюдження ще не підтверджене**: відкриті питання нижче.

Перевірено всі 47 сторонніх пакетів із uv.lock (runtime, dev, Windows), тексти
ліцензій установленого Python 3.12 середовища, Dockerfile, static/templates і
повідомлення у двох PDF. Source-архіви colorama та pyxroad завантажені за URL
із lock і перевірені за його SHA-256. Перевірено тег pyxroad v1.5.10:
`aed1635f858f3a13006aff629631e77d97379636`.

1. **pyxroad 1.5.10.** Отримати від правовласника повний MIT notice із належним
   copyright і включити його в third_party_licenses та наступний upstream-реліз.
   MIT задекларовано у metadata/README, але LICENSE відсутній у wheel, sdist і
   відповідному git-тегу. Не можна вигадати імена чи роки copyright.
2. **Конкретний Docker-образ і native-компоненти.** Побудувати та інвентаризувати
   фактичний образ, зафіксувати digest базового образу й версії OS/uv/native libs.
   Зберегти їхні notices та виконати source/relinking-вимоги GPL/LGPL, якщо вони
   застосовуються до включених компонентів. lxml LICENSES.txt згадує iconv LGPL-2.1,
   zlib, libxml2/libxslt/libexslt та окремі ресурси. Треба перевірити фактичну
   комплектацію wheel і доступність відповідного коду/матеріалів перелінкування.
   Зібрані package notices самі по собі не закривають цей пункт.
3. **Доступ користувачів до коду.** Для фактичного розгортання надати користувачам
   доступ до точного коду сервісу й oots-lib та ліцензій через канал надання послуги.
   Вказаний GitHub URL взято з git remote; його публічну доступність не перевірено.
   Локальна наявність коду в контейнері не забезпечує доступ мережевим користувачам.

Ці питання не є доведеними конфліктами ліцензій, але не дозволяють позначити весь
дистрибутив як повністю compliant. Публікація образу/коду в межах аудиту не виконувалась.

## Повторення аудиту

```sh
uv sync --frozen --extra dev
uv run --no-sync python tools/collect_licenses.py --output /tmp/eidas-license-notices
```

Скрипт збирає докази з поточного середовища, перевіряє відповідність версій lock
і явно показує відсутні пакети/тексти. Він не є автоматичним юридичним схваленням.
На Linux colorama треба окремо взяти з source-архіву, перевіреного за uv.lock.
Переглянути ліцензії, вкладені компоненти й відкриті питання після кожної зміни
залежностей; потім оновити notices та inventory. Не замінювати перевірений
інвентар неповним результатом із іншої платформи.
